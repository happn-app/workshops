# Type-Driven Development & Error Handling – Workshop Support

This repository is used as support material for a technical talk/workshop about **Type-Driven Development** and **error handling** in Kotlin.

The code in this project illustrates how to:

- Use types to model the domain and error cases explicitly.
- Make illegal states and invalid flows impossible.
- Let the type system drive error handling strategies and guide refactoring.

It is not a production-ready application, but a playground to explore type-driven design and error modeling during the presentation.
